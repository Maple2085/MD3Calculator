# MD3 Calculator

一个基于 Material Design 3 的 Kotlin 计算器 APP

## 特性

- 🎨 Material You 动态配色
- 📱 Jetpack Compose 声明式 UI
- ➕ 基础四则运算
- 🔄 支持小数点运算
- ⌫ 退格和清空功能

## 技术栈

- Kotlin 2.0.21
- Jetpack Compose
- Material 3 (动态主题)
- Android Gradle Plugin 8.7.3

## 构建

本项目使用 GitHub Actions 自动构建 APK。

每次推送到 `main` 分支时会自动触发构建，生成的 APK 可以在 Actions 页面下载。

## 开发环境

- compileSdk: 35
- minSdk: 24 (Android 7.0+)
- targetSdk: 35
